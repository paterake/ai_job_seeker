# Agent Skills

PCO-level skills available to all governed repos: one folder per skill in this directory, each defined by its own
`SKILL.md`. A skill's purpose and trigger is the `description` in its frontmatter; its lifecycle stage, if
registered, is in [capability_registry.yaml](../../governance/capability_registry.yaml). How skills are wired, and
how project skills combine with these: [CONTRACT.md](../../governance/CONTRACT.md) → What a Target Repo Must Look
Like.
